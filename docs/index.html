玩法简介

  • 玩家操控主角击退来袭怪物，保护主塔不被摧毁
  • 多波次生成、NavMesh 寻路、动画事件驱动攻击判定
  • 炮塔放置/升级、武器系统、金币与波次结算
  • 对象池管理特效，避免高频 Instantiate/Destroy 造成的 GC 抖动
